# Kotoba — MCO : cours de vocabulaire et lectures des kanji

29 cours de vocabulaire, 230 entrées, dont 184 écrites avec des kanji ; 167 caractères distincts. Chaque MCO contient au maximum dix entrées. Étudie la lecture du mot et son sens, puis les références kun’yomi et on’yomi de ses caractères. Les emprunts et les expressions couramment écrits en kana gardent leur écriture naturelle.

Les textes, exemples et exercices sont originaux. Les références de lectures proviennent des sources attribuées en fin de document. Kotoba 0.3.4 fournit directement ces MCO dans le programme embarqué ; aucun import JSON n’est nécessaire. Les dessins de l’atelier ne sont pas corrigés automatiquement.

**Kun’yomi, on’yomi et lecture du mot**

Kun’yomi désigne les lectures japonaises d’un kanji ; on’yomi désigne les lectures d’origine chinoise adaptées au japonais. Dans ces fiches, les kun sont notés en hiragana et les on en katakana : c’est une convention de dictionnaire, pas la façon d’écrire le mot dans une phrase.

Le mot possède sa lecture en kana. Les listes de caractères sont des repères : on ne choisit pas une lecture au hasard pour recomposer le mot. Un caractère seul peut utiliser on ; un composé peut associer kun et on ou posséder une lecture particulière.

Le point dans た.べる sépare la lecture portée par le kanji 食 des kana べる (okurigana). On écrit 食べる, sans point. Une liste vide signifie qu’aucune lecture usuelle de ce type n’est présentée dans cette référence ; il ne faut pas en inventer. Les lectures proposées ne forment pas un dictionnaire exhaustif.

**Kun’yomi, on’yomi et lecture du mot**

Kun’yomi désigne les lectures japonaises d’un kanji ; on’yomi désigne les lectures d’origine chinoise adaptées au japonais. Dans ces fiches, les kun sont notés en hiragana et les on en katakana : c’est une convention de dictionnaire, pas la façon d’écrire le mot dans une phrase.

Le mot possède sa lecture en kana. Les listes de caractères sont des repères : on ne choisit pas une lecture au hasard pour recomposer le mot. Un caractère seul peut utiliser on ; un composé peut associer kun et on ou posséder une lecture particulière.

Le point dans た.べる sépare la lecture portée par le kanji 食 des kana べる (okurigana). On écrit 食べる, sans point. Une liste vide signifie qu’aucune lecture usuelle de ce type n’est présentée dans cette référence ; il ne faut pas en inventer. Les lectures proposées ne forment pas un dictionnaire exhaustif.

**今日 · きょう**

Sens : aujourd’hui. Écriture étudiée : 今日 ; lecture du mot : きょう.

日 — kun’yomi : ひ・か ; on’yomi : ニチ・ジツ.

**明日 · あした**

Sens : demain. Écriture étudiée : 明日 ; lecture du mot : あした.

Autres lectures admises pour le sens de cette fiche : あす.

明日 se lit ici あした ; あす est une autre lecture usuelle pour demain. La lecture appartient au mot entier et ne se déduit pas simplement de 明 et 日.

明 — kun’yomi : あける・あかるい・あからむ・あきらか ; on’yomi : メイ・ミョウ.

日 — kun’yomi : ひ・か ; on’yomi : ニチ・ジツ.

**Kun’yomi, on’yomi et lecture du mot**

Kun’yomi désigne les lectures japonaises d’un kanji ; on’yomi désigne les lectures d’origine chinoise adaptées au japonais. Dans ces fiches, les kun sont notés en hiragana et les on en katakana : c’est une convention de dictionnaire, pas la façon d’écrire le mot dans une phrase.

Le mot possède sa lecture en kana. Les listes de caractères sont des repères : on ne choisit pas une lecture au hasard pour recomposer le mot. Un caractère seul peut utiliser on ; un composé peut associer kun et on ou posséder une lecture particulière.

Le point dans た.べる sépare la lecture portée par le kanji 食 des kana べる (okurigana). On écrit 食べる, sans point. Une liste vide signifie qu’aucune lecture usuelle de ce type n’est présentée dans cette référence ; il ne faut pas en inventer. Les lectures proposées ne forment pas un dictionnaire exhaustif.
