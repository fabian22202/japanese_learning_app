# Kotoba · 0.3.4


Kotoba is a free, and open source app that uses a mix of Duolingo and Anki features to offer a dynamic way and better way to learn.
This app is based on Flutter and Dart.

# How to install

This app is only available on Windows and Android for now, will build Debian and Arch Linux app soon as well as a Mac image.
To download it's simple :
Go to Release and download desired version (0.34) or download latest version by clicking one of these links : 

[Download Android](https://github.com/fabian22202/japanese_learning_app/releases/download/0.1/Kotoba-Android.zip)
[Download Windows](https://github.com/fabian22202/japanese_learning_app/releases/download/0.1/Kotoba-Windows.zip)

# What's inside :

For now these apps simply contains a French course over Japanese this app was in fact developed to learn Japanese
